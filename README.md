# OShelper v1.0

Лёгкий лаунчер и каталог полезных программ для Windows, кастомизация оттенка темы, поиск, фильтрация по категориям и пакетным открытием ссылок.

### Установка и запуск
1. Скачайте **`OShelper_Setup.exe`** из блока **Assets** ниже.
2. Запустите установщик и следуйте инструкциям мастера (при необходимости можно создать ярлык на рабочем столе).
3. Если при первом запуске файла или программы **Windows SmartScreen** покажет синее окно защиты (из-за отсутствия платной цифровой подписи), нажмите **«Подробнее» → «Выполнить в любом случае»**.

### Что внутри
* Категории программ: *Лаунчеры*, *Мессенджеры*, *Браузеры*, *Кастомизация*, *Утилиты*, *Система*.
* Быстрый поиск и выбор сразу нескольких программ через чекбоксы.
* Смена оттенка акцента и сворачивание в системный трей.
